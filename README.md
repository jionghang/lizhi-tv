# 荔枝直播

在安卓电视盒子上像传统电视一样，用遥控器观看广东广播电视台的电视和广播频道。

## 项目说明

应用内嵌 Firefox 的渲染引擎 GeckoView，启动后加载广东台官网的频道页面。
画面、播放地址与鉴权参数均由官网页面自行生成，本项目只负责把页面铺满屏幕、
把遥控器按键映射为换台操作，并在画面上覆盖一层自有界面。

仓库中不包含任何抓取、解析或转存流地址的代码，也不包含绕过鉴权的处理。
播放能力完全取决于官网，官网改版本项目随之调整。

## 支持功能

电视共十八个频道，广东卫视、珠江、新闻、民生、体育、影视、少儿、嘉佳卡通、
岭南戏曲、大湾区卫视、4K 超高清、纪录片、健康等均已收录。

广播共八个频率，新闻广播、珠江经济台、音乐之声、交通之声、南方生活、
城市之声、文体广播、珠江之声。

遥控器方向键换台，数字键直达对应频道，确认键打开频道列表，菜单键打开设置，
返回键返回桌面。

## 构建

构建前需自行准备 GeckoView 69 的 AAR 包，体积约一百五十兆，未纳入仓库，
放置于 libs 目录即可。随后在 Git Bash 中执行 build.sh，产物输出至 out 目录。

构建链路为 aapt2、javac、d8 与 apksigner，不依赖 Gradle。
