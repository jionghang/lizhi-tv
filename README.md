# 荔枝直播

在安卓电视盒子上用遥控器看广东广播电视台的电视和广播频道。

## 它到底做了什么

应用里嵌了一个 Firefox 的渲染引擎 GeckoView，启动后加载广东台官网的频道页面。
画面、播放地址和鉴权参数全部由官网页面自己生成，这个应用只做三件事：把页面铺满屏幕，
把遥控器按键接到换台上，再在画面上盖一层自己的界面。

所以仓库里没有任何抓取、解析或者转存流地址的代码，也没有绕过鉴权的东西。
官网能播就能播，官网改版它也跟着改。

## 能做什么

电视有十八个频道，广东卫视、珠江、新闻、民生、体育、影视、少儿、嘉佳卡通、
岭南戏曲、大湾区卫视、4K 超高清、纪录片、健康这些都在里面。

广播有八个频率，新闻广播、珠江经济台、音乐之声、交通之声、南方生活、
城市之声、文体广播、珠江之声。

遥控器上方向键换台，数字键直接跳到对应频道，确认键打开频道列表，菜单键打开设置，
返回键回桌面。

## 怎么构建

需要自备 GeckoView 69 的 AAR 包。它有一百多兆，所以没有放进仓库，放到 libs 目录下就行。
然后在 Git Bash 里执行 build.sh，产物在 out 目录。

构建用的是 aapt2、javac、d8、apksigner 这套命令行工具，不需要 Gradle。

## 版权

频道、节目和流媒体的版权都归广东广播电视台所有。这个项目只是把官网页面装进盒子里，
供自己在家里看，请不要拿去做商业用途或者二次分发。
